# Trace(자국)

> 결과만 남는 작업에서, **과정을 남긴다.**
> 학생이 컴퓨터로 공부하고 작업하는 과정을 기록해, 배우기 위해 돌아보거나(Learn) 바뀌지 않았음을 증명한다(Proof).

이 문서는 **처음 보는 사람(개발 전공이 아니어도)**이 이 프로젝트가 무엇이고, 왜 이렇게 만들었는지,
지금 어디까지 왔는지 이해할 수 있도록 쓰여졌습니다. 진행이 있을 때마다 6절(지금 상태)을 갱신합니다.

> 📦 **완성의 기준 (10주 · 2인):** 학생 PC의 **수집기 → 서버·DB → 앱 화면(React, PC 앱 창)** 이 한 바퀴 돌고,
> Proof Mode에서 **증명서 1장**이, Learn Mode에서 **Learning Session Report** 가 나오는 것.
> 수집기·해시 체인·참고 서버·화면 설계(목업 22장)는 되어 있고, 남은 것은 **서버·DB·React·브라우저 확장** 입니다.
> 🧭 최종 기획서(A와 합의본)가 기준이고, 어제 결정한 것과 이번 주 할 일은 [1-기획/1-개발 로드맵](1-기획/1-개발%20로드맵%20(10주·B).md)에,
> 서버와 주고받는 규칙은 [1-기획/2-API 계약](1-기획/2-API%20계약%20초안%20(docs-api).md)에 있습니다.

## 1. 무슨 문제를 푸나

AI 시대에 학생은 검색·생성형 AI·IDE·문서 프로그램을 동시에 쓰며 과제를 합니다. 그래서 **최종 결과물만으로는**
그 사람이 어떤 과정을 거쳤는지 알 수 없게 됐습니다. 같은 결과물이라도

- 직접 오류를 찾고 공부하며 완성한 경우와
- AI 답변을 그대로 가져와 완성한 경우

는 배운 것이 전혀 다릅니다. 이 차이는 두 가지 상황에서 문제가 됩니다.

| 상황 | 곤란한 사람 | Trace가 하는 일 |
|---|---|---|
| **배우는 중** — "AI에 기대다 보니 내가 뭘 배웠는지 나도 모르겠다" | 학생 본인 | **Learn Mode** — 무엇을 물었고 그 뒤에 무엇을 직접 고쳤는지 맥락까지 기록, AI가 학습 과정을 정리 |
| **증명해야 할 때** — AI 금지 과제·시험·코딩 테스트·공모전에서 "직접 했다"를 보여줄 방법이 없다 | 제출하는 사람 | **Proof Mode** — 어떤 프로그램에서 언제 무슨 일이 있었는지를 해시 체인으로 봉인해 사후 변조 불가능한 기록으로 |

## 2. 핵심 아이디어

**① 기록하되, 판정하지 않는다**
"AI 사용 확률 78%" 같은 점수를 만들지 않습니다. 직접 입력 57% / 붙여넣기 43%는 **사실**이고, 그게 좋은지 나쁜지는
보는 사람이 정합니다. AI 탐지기는 오탐으로 여러 대학이 사용을 중단했습니다 — 우리는 탐지기가 아니라 **거울**입니다.

**② 같은 수집기, 다른 출력**
학생 PC의 수집기 하나가 활성 창·입력 횟수·복사/붙여넣기·파일 저장을 기록합니다. Learn은 그 위에 맥락(AI 질문·답변 발췌 등)을
더해 **리포트**로, Proof는 맥락 없이 사실만 **해시 체인 → 증명서**로 냅니다. 한 세션은 한 모드입니다.

**③ 내용은 필요한 만큼만, 항목별로 끈다**
Proof는 내용을 전혀 읽지 않습니다 — 키는 **횟수만**, 클립보드는 **길이와 해시만**, 화면은 안 찍습니다.
Learn은 학습 분석에 필요한 맥락(AI 질문·답변 중 복사한 부분·참고 페이지·오류)을 읽되, **항목마다 켜고 끌 수 있고**
기록은 학생 본인만 봅니다. 교수에게 자동으로 가는 경로는 없습니다.

**④ 체인은 양쪽에서 만든다**
해시 체인을 학생 PC에서 만들고, 서버가 같은 이벤트로 **다시 계산해 대조**합니다. PC에만 있으면 학생이, 서버에만 있으면
운영자가 고칠 수 있기 때문입니다. 둘이 서로 확인하면 어느 쪽도 혼자 못 고치고, 제3자는 **서버 없이도** 검증할 수 있습니다.

## 4. 기능별 설명 — 무엇을 / 왜

### 수집기 (Python · 윈도우 · 완료)
- **왜:** 브라우저는 자기 탭 밖을 못 봅니다. 다른 앱 이름·클립보드·키 횟수·파일 저장은 PC에 설치된 프로그램만 볼 수 있습니다.
- **뭘:** 1초마다 활성 창(앱 이름·제목), 클립보드 변경(길이·SHA-256), 입력·삭제 횟수(10초 단위), Ctrl+V/Z/Y/X, 감시 폴더 저장,
  5분 무입력, 30초 heartbeat. Word·PowerPoint가 앞에 있으면 **문서가 어디서 몇 자 늘고 줄었는지**(숫자만)도. **화이트리스트 밖 앱은 이름만 남고 제목은 안 남습니다.** 이벤트마다 체인 해시를 붙여 로컬 파일에
  먼저 쓰고, 5초/50건 단위로 서버에 보냅니다. 서버가 꺼지면 큐에 쌓였다가 순서대로 재전송됩니다.

### 해시 체인 · 봉인 (완료 — 서버 앵커만 남음)
- **왜:** "이 기록은 나중에 고쳐진 게 아니다"를 누구든 확인할 수 있어야 Proof가 성립합니다.
- **뭘:** hᵢ = SHA256(hᵢ₋₁ ‖ 시각 ‖ 종류 ‖ 요약). [`3-코드/core/chain.py`](3-코드/core/chain.py) 하나를 수집기·서버·화면이 같이 씁니다.
  배치마다 체인 해시를 보내고 서버가 재계산해 대조, 수신 시각을 기록해 5분 넘게 늦은 구간은 "지연 수신"으로 표시합니다.
  세션 종료 때 루트 해시를 확정하고 OpenTimestamps에 앵커합니다(서버 쪽, A 구현 예정).

### Proof Mode 화면 — 한눈에 · 증명서 (설계 완료 · 뷰어 동작)
- **왜:** 검증자는 로그를 읽을 시간이 없습니다. 두 숫자와 그래프 하나로 "직접 쳤는지 붙여넣었는지"가 보여야 합니다.
- **뭘:** 직접 입력 % / 붙여넣기 % → 구성 막대 → 레인 그래프 4줄(활성 창 · 직접 입력 · 붙여넣기 · 삭제/되돌리기) → 앱별 활동 →
  **▶ 상세 활동 보기**(창이 바뀔 때마다 한 줄, 접혀 있음) → 핵심 순간. 붙여넣기는 "Chrome · Claude에서 복사한 것"처럼 **출처 창 이름**으로.
  빨강은 오직 AI 앱·사이트에서 복사한 것에만. 증명서는 A4 한 장 + 검증 파일(.json/.ots) + 설치 없는 검증 웹.

### Learn Mode — 맥락 · Side Chat · Report (설계 완료 · 구현 예정)
- **왜:** 이벤트만으론 "왜 AI를 썼는지"를 모릅니다. 오류 → 질문 → 답변 참고 → 직접 수정 → 해결이라는 **맥락**이 있어야 학습 과정이 됩니다.
- **뭘:** 브라우저 확장이 AI 질문·답변 발췌·선택 텍스트·참고 페이지를 보냅니다(Must). **Word·PowerPoint는 이미 됩니다** — 열린 문서의
  바뀐 문단·도형만(내용 ≤500자), 붙여넣은 자리, 저장 시 글자 수. VS Code(Should)가 남았고, 시간이 부족하면 거기서 멈춥니다. AI에게 묻는 길은 둘: **알약 위의 작은 질문칸**(항상 떠 있음, 누르면 채팅 패널이 위로 펼쳐졌다 ✕로 닫힘 — 웹에 가지 않고 바로 묻기)과
  코드를 드래그했을 때 뜨는 작은 툴바 → Side Chat. 둘 다 같은 `/chat` 이고 대화는 세션 맥락에 남습니다. 학생이 리포트를 **열 때** AI가
  주요 학습 내용 · 어려움 · 학습 과정 · 학습 포인트 · 추가 학습을 정리한 리포트를 만듭니다(세션 종료 시 자동 생성 안 함 — 안 보는 세션엔 비용 0). 점수 없음, 공유 없음.

### 정직성 원칙
- **왜:** 감시 도구로 읽히는 순간 학생은 켜지 않습니다. 이 프로젝트의 가장 큰 위험은 기술이 아니라 **감시로 오인되는 것**입니다.
- **뭘:** 증명서·검증 화면에 **"증명하는 것 / 증명하지 않는 것"** 을 항상 나란히 씁니다 — 순서·시각·불변은 증명하지만
  "AI를 안 썼다", 저자가 누구인지, 품질은 증명하지 않습니다. 지연 수신·체인 불일치·공백은 숨기지 않고 표시합니다.
  키 훅은 [`keys.py`](3-코드/collector/keys.py) 파일 자체가 "횟수만 센다"는 증거입니다.

## 5. 심사 포인트 — 창의성 · 사업성 · 보안

### 🎨 창의성 — "AI를 썼나"가 아니라 "AI를 쓴 뒤 무엇을 했나"를 데이터로

기존 도구는 전부 **기관이 학생을 보기 위해** 만들어졌습니다(Turnitin Clarity·시험 감독 프로그램). 결과물 기반 AI 탐지는
오탐으로 실패했습니다. Trace는 **학생이 자기를 보기 위한** 도구이고, 자료 → AI → 작업 사이의 **전환**을 한 타임라인에 놓는
서비스는 아직 없습니다. 같은 데이터라도 주인이 다릅니다 — "Turnitin은 교수가 학생을 보게 한다. 우리는 학생이 자기를 보게 한다."

- 실측: 9/20 첫 실데이터 7분 세션에서 "Claude 앱에서 복사 → 카카오톡 붙여넣기(같은 해시, AI 출처)"와
  "탐색기에서 복사 → 붙여넣기(같은 해시, AI 아님)"가 정확히 구분됐습니다. 판정이 아니라 사실 표기만으로.

### 💰 사업성 — 학생은 무료, 변동비 ≈ 0

- 기록은 학생 PC에 먼저 저장되고 서버에는 이벤트만 갑니다 — 한 세션 2시간 ≈ 260KB, 학생 30명 한 학기 ≈ 470MB.
  검증도 브라우저 안에서 계산되므로 **서버 비용이 거의 없습니다.**
- 과금 대상은 학생이 아니라 **보는 쪽**(수업·학과·공모전 주최)입니다. 학생이 자기 기록을 보는 데 돈을 받지 않는 것이 원칙이고,
  Proof 증명서는 건당 과금이 가능합니다. 구체 가격은 파일럿 뒤 교수 인터뷰로 정합니다.
- 받지 않는 돈: 광고 · AI 판정 점수 판매 · 학생 데이터 판매. 하나라도 받으면 "학생이 주인"이 깨집니다.
- **Learn의 AI 비용은 상한으로 묶여 있습니다** — **GPT-5.6 Luna 기준 학생 1명 한 학기 약 440원**(리포트 36회 + 채팅 180턴). 리포트는 학생이 열 때만 만들고(안 보면 0원), 채팅은 세션당 30턴. 학생당 3,000원 라이선스 안에서 남습니다. Sonnet 5 를 쓰면 4,300원으로 적자 — **모델 선택이 곧 사업성**입니다.

  | 모델 | 입력 / 출력 (100만 토큰) | 학생 1명·학기 | 파일럿 30명·학기 |
  |---|---|---|---|
  | Qwen3.5 Flash | $0.10 / $0.40 | 175원 | 5천 원 |
  | **GPT-5.6 Luna** (채택) | **$0.20 / $1.20** | **440원** | **1.3만 원** |
  | GPT-5.4 Nano | $0.20 / $1.25 | 450원 | 1.4만 원 |
  | Qwen-Plus | $0.40 / $1.20 | 650원 | 1.9만 원 |
  | GPT-5.4 Mini | $0.75 / $4.50 | 1,900원 | 5.7만 원 |
  | Claude Sonnet 5 | $2.00 / $10.00 | 4,300원 | 12만 원 |

  ★ **OpenAI 최저가가 Qwen-Plus 보다 싸다** — 처음엔 “Qwen 이 싸다”고 봤는데, 그건 Qwen3.5 Flash(175원) 이야기였고 우리가 쓰려던 것은 Qwen-Plus(650원)였다. 급이 다른 것을 비교하고 있었다. 가격까지 유리해서 **GPT-5.6 Luna 로 정했다 (9/21, 팀 결정)**. 단가는 발표 전에 각 공급자 공식 가격표로 다시 확인할 것.

### 🔒 보안 · 개인정보 — 무엇을 안 읽는지가 설계의 절반

| 위협 | 대응 | 상태 |
|---|---|---|
| **학생이 기록을 지어냄** | 체인이 아니라 **실시간 전송 + 서버 수신 시각**으로 잡음. 5분 넘게 늦은 구간은 증명서에 "지연 수신" | ✅ 수집기·참고 서버 구현 |
| **학생이 로컬 파일을 나중에 고침** | 5초마다 서버에 해시가 가 있음. 서버 재계산과 어긋나면 "무결성 오류" | ✅ |
| **운영자(우리)가 DB를 고침** | 학생 PC에 원본+체인 사본, 루트는 외부 앵커. 대조하면 들통 | 🔄 앵커 실제 제출 (A) |
