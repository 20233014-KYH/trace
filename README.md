## 1. 무슨 문제를 푸나

**대학생은 과제 제출 후 AI 사용을 의심받거나 밝혀야 하는 상황에서, 작성 과정이 기록으로 남지 않기 때문에, 자기가 직접 한 일을 보여주지 못합니다.**

직접 쓴 글이 AI 탐지기에서 49%·70% 판정을 받고, 학생은 "안 썼다는 것을 어떻게 증명하냐"며 글을 망가뜨리거나 다시 씁니다.
교수는 탐지를 믿기 어려워 지필고사로 돌아갑니다. 교육부는 "탐지 결과만으로 판단하지 말고 과정을 확인하라"고 하지만,
**확인할 과정 기록이 어디에도 없습니다.**

| 상황 | 곤란한 사람 | Trace가 하는 일 |
|---|---|---|
| **AI 허용 과제에서 내역을 내야 함** | 쓴 학생 | 어떤 AI에 무엇을 묻고 답을 어떻게 고쳐 썼는지가 손 정리 없이 내역서로 |
| **팀 과제에서 자기 몫을 못 보여줌** | 실제로 한 사람 | 각자 기록 → 과제 단위로 합침 (시간 남으면) |

**교수는 Trace를 설치하지 않습니다.** 내역서 1장을 받고, 근거가 궁금할 때만 링크를 엽니다.

> 9/30: **AI 금지 과제는 대상에서 뺐습니다.** 위 탐지기 사례는 "결과물만으로는 누가 얼마나 했는지 모른다"는 배경입니다.

## 2. 핵심 아이디어

**① 기록하되, 판정하지 않는다**
"AI 사용 확률 78%" 같은 점수를 만들지 않습니다. 직접 입력 57% / 붙여넣기 43%는 **사실**이고, 그게 좋은지 나쁜지는
보는 사람이 정합니다. 결과물 기반 AI 탐지는 오탐으로 여러 대학이 사용을 중단했습니다 — 우리는 탐지기가 아니라 **거울**입니다.

**② 대상은 AI 허용 과제, 출력은 AI 활용 내역서 하나 (9/30)**
AI 금지 과제는 뺐습니다 — "안 썼다"는 휴대폰·다른 PC·보고 치기로 뚫려서 약속할 수 없습니다. `ai_policy` 도 없앴고,
과제에는 교수가 허용한 범위를 적는 선택 메모 `ai_scope` 만 둡니다. 내역서 1장 = "허용 범위·쓴 AI·질문 수·결과물에서 AI 답과
연결된 곳(그대로/고침)·출처 기록 없음 구간·작업 시간".

**③ 기록 없는 곳은 "직접 씀"이 아니라 "출처 기록 없음"**
Trace는 휴대폰이나 다른 PC에서 쓴 AI를 못 잡습니다. 없는 걸 있다고, 있는 걸 없다고 단정하지 않는 것이
이 서비스가 신뢰를 얻는 유일한 방법입니다. 화면·PDF에 그대로 "출처 기록 없음"으로 씁니다.

**④ 체인은 양쪽에서 만든다**
해시 체인을 학생 PC에서 만들고, 서버가 같은 이벤트로 **다시 계산해 대조**합니다. PC에만 있으면 학생이, 서버에만 있으면
운영자가 고칠 수 있기 때문입니다. 둘이 서로 확인하면 어느 쪽도 혼자 못 고칩니다.

**⑤ 학생이 켜고, 확인하고, 제출한다**
교수에게 자동으로 가는 경로는 없습니다. 학생이 제출 전에 **가릴 수 있고**, 가린 자리는 "가림"으로 남되
체인 검증은 해시로 계속 됩니다.

## 4. 기능별 설명 — 무엇을 / 왜

### 기록기 (Python · 윈도우 · 완료)
- **왜:** 브라우저는 자기 탭 밖을 못 봅니다. 다른 앱 이름·클립보드·키 횟수·파일 저장은 PC에 설치된 프로그램만 볼 수 있습니다.
  Grammarly Authorship이 한 창 안에서만 보는 것과 우리가 갈라지는 지점입니다.
- **뭘:** 1초마다 활성 창(앱 이름·제목), 클립보드 변경(길이·SHA-256), 입력·삭제 횟수(10초 단위), Ctrl+V/Z/Y/X, 감시 폴더 저장,
  5분 무입력, 30초 heartbeat. Word·PowerPoint가 앞에 있으면 문서가 어디서 몇 자 늘고 줄었는지와 **바뀐 텍스트**(결과물–AI 답 비교 재료)도.
  이벤트마다 체인 해시를 붙여 로컬 파일에 먼저 쓰고, 5초/50건 단위로 서버에 보냅니다. 서버가 꺼지면 큐에 쌓였다가 순서대로 재전송됩니다.

### 브라우저 확장 (뼈대 완료 · 질문 원문은 10월 1주)
- **왜:** AI 답을 어떻게 고쳐 썼는지 보여주려면 **원래 답이 무엇이었는지**를 알아야 합니다.
- **뭘:** AI 사이트의 질문·답 원문, 탭 전환, 참고 페이지. 항목별로 켜고 끌 수 있습니다.
  **`mode === "learn"` 조건을 없애고 항상 수집으로 바꿔야 합니다** (수정사항 4-1).

### 해시 체인 · 봉인 (완료)
- **왜:** "이 기록은 나중에 고쳐진 게 아니다"를 누구든 확인할 수 있어야 합니다.
- **뭘:** hᵢ = SHA256(hᵢ₋₁ ‖ 시각 ‖ 종류 ‖ 요약). [`3-코드/core/chain.py`](3-코드/core/chain.py) 하나를 기록기·서버·화면이 같이 씁니다.
  배치마다 체인 해시를 보내고 서버가 재계산해 대조, 어긋나면 `verified:false`·봉인 409.
  실측: 글자 수 1 변경과 기록 1개 삭제를 모두 잡았습니다.

### 요약 1장 (예정 · 10주)
- **왜:** 교수는 로그를 읽을 시간이 없습니다. 한 장으로 끝나야 합니다.
- **뭘:** "과제 끝"을 누르면 1장 PDF. **규칙 기반이 기본** — 기록에서 센 숫자로 만듭니다(지어낼 수 없음, 외부 전송 없음, 비용 0).
  LLM 문장 요약은 **학생이 켤 때만** 쓰는 선택 기능이고, 결과는 학생이 확인·수정한 뒤 제출합니다.

### 의심받을 때 과정 공개 (예정 · 11주)
- **왜:** 탐지기가 의심했을 때 **그때만** 열 수 있어야 감시가 아닙니다.
- **뭘:** 공유 링크를 열면 학생이 확인한 연결마다 원래 AI 답과 고친 결과가 **나란히** 뜹니다(점수 없음).
  기록을 고쳤으면 "조작됨". 교수는 로그인 없이 링크로만.

### AI 답 연결 (예정 · 10주)
- **왜:** 복사해서 그대로 붙이면 해시로 잡히지만, **고쳐서 붙이거나 보면서 다시 치면** 못 잡습니다.
- **뭘:** 해시가 같으면 자동 연결. 비슷하면 Trace가 제안하고 **학생이 맞다/아니다를 고릅니다.**
  "아니다"를 골라도 "제안했고 연결하지 않음"이 체인에 남습니다(지울 수 없음).
  **퍼센트 유사도는 화면에 절대 내지 않습니다.** 비교 단위는 문장, 정확도가 부족하면 문단.

### 정직성 원칙
- **왜:** 감시 도구로 읽히는 순간 학생은 켜지 않습니다. 이 프로젝트의 가장 큰 위험은 기술이 아니라 **감시로 오인되는 것**입니다.
- **뭘:** 화면·PDF에 **"증명하는 것 / 증명하지 않는 것"** 을 항상 나란히 씁니다 — 순서·시각·불변은 증명하지만
  "AI를 안 썼다", 저자가 누구인지, 품질은 증명하지 않습니다. 지연 수신·체인 불일치·공백은 숨기지 않습니다.
  키 훅은 [`keys.py`](3-코드/collector/keys.py) 파일 자체가 "횟수만 센다"는 증거입니다.

## 5. 심사 포인트 — 창의성 · 사업성 · 보안

### 🎨 창의성 — 결과물이 아니라 과정을, 한 앱이 아니라 여러 앱을

| 사례 | 남은 한계 | 우리 |
|---|---|---|
| **Grammarly Authorship** (미국) | 글 쓰는 창 **안에서만**. 코드는 못 보고, 외부 AI 대화와 연결 못 해 보고 옮겨 친 글은 '직접 타이핑'으로 분류 | AI 서비스·VS Code·Word를 **오가는 과정을 통째로** |
| **카피킬러 GPT킬러** (한국) | 결과물만 보고 확률 추정. 교육부·숭실대 모두 이것만으론 어렵다고 함 | **판정·점수 없음.** 의심되면 그때 과정을 열어 확인 |

- 실측: 9/20 첫 실데이터에서 "Claude 앱에서 복사 → 카카오톡 붙여넣기(같은 해시, AI 출처)"와
  "탐색기에서 복사 → 붙여넣기(같은 해시, AI 아님)"가 정확히 구분됐습니다. 판정이 아니라 사실 표기만으로.

### 💰 사업성 — 학생은 무료, 변동비 ≈ 0

- 기록은 학생 PC에 먼저 저장되고 서버에는 이벤트만 갑니다 — 한 세션 2시간 ≈ 260KB, 학생 30명 한 학기 ≈ 470MB.
- **요약이 규칙 기반이라 AI 비용이 기본 0원입니다.** LLM 문장 요약은 학생이 켤 때만 도는 선택 기능이라,
  아래 표는 "켠 학생"에 대한 상한일 뿐입니다.

  | 모델 | 입력 / 출력 (100만 토큰) | 켠 학생 1명·학기(상한) |
  |---|---|---|
  | Qwen3.5 Flash | $0.10 / $0.40 | 175원 |
  | **GPT-5.6 Luna** (채택) | **$0.20 / $1.20** | **440원** |
  | Claude Sonnet 5 | $2.00 / $10.00 | 4,300원 |

  단가는 발표 전에 각 공급자 공식 가격표로 다시 확인할 것.
- 과금 대상은 학생이 아니라 **보는 쪽**(수업·학과·공모전 주최)입니다.
- 받지 않는 돈: 광고 · AI 판정 점수 판매 · 학생 데이터 판매. 하나라도 받으면 "학생이 주인"이 깨집니다.

### 🔒 보안 · 개인정보 — 무엇을 안 읽는지가 설계의 절반

| 위협 | 대응 | 상태 |
|---|---|---|

| **학생이 로컬 파일을 나중에 고침** | 5초마다 서버에 해시가 가 있음. 서버 재계산과 어긋나면 "조작됨" | ✅ |
| **운영자(우리)가 DB를 고침** | 학생 PC에 원본+체인 사본. 대조하면 들통 | ⚠️ 외부 시간 도장은 이번 학기 제외 |
| **대리 작업 · 기록기 개조** | 어떤 체인도 못 막음 → **"증명하지 않는 것"에 명시** | ✅ |
| **개인정보 — 창 제목에 사적 내용** | 화이트리스트 밖 앱은 제목 없이 이름만. 키 내용·화면 없음 | ✅ |
| **기록이 감시로 읽힘** | 항목별 토글 · 제출 전 가리기 · 교수 자동 공유 경로 없음 | 🔄 가리기 구현 예정 |
| **AI 대화에 API 키·개인정보가 섞임** | AI로 보내기 전 자동으로 가림 | 📅 미구현 |
| **서버 API 키·인증** | 로그인 토큰, 세션 id는 클라이언트 UUID(오프라인 대비), 서버는 중복 무시(멱등) | ✅ |

  브라우저 확장 ─ AI 사이트 질문·답 원문 · 탭 ─→ 127.0.0.1:5077 다리 ──────────────────┤ (core/chain.py)

                                       5초/50건 batch + chain_head  →  POST /api/sessions/{id}/events
                                                                            ▼

  같은 chain.py 로 재계산 → 대조 · 수신 시각 · 지연 판정 · 봉인 시 루트 확정
  출처 찾기(해시 일치 → 자동 연결 · 유사 → 학생에게 제안) · 규칙 기반 요약 · 공유 링크 토큰
  (선택) core/llm.py → 요약 문장만. 학생이 켤 때만

## 9. 협업 규칙

- **2인 분업:** 김용현 = 서버·DB·로그인, 요약 PDF, 공유 링크. 박상진 = 기록기·브라우저 확장, 문장 출처 찾기, 요약 화면.
  자르는 원칙은 **"내가 만든 데이터는 내가 화면까지 그린다."**
- **계약 3개**가 있어야 서로 안 기다린다: ① 이벤트 한 줄 · ② session.json · ③ API(`docs/api.md`).
  바꾸면 상대에게 알린다. **해시 계산은 `core/chain.py` 밖에서 하지 않는다.**
- **관문은 미루지 않는다.** 10/7 첫 연결은 기능을 줄여서라도 그 주에 끝에서 끝까지 한 번 돌린다.
- **Git:** 하루 시작할 때 `git pull` · 기능별 브랜치 → PR로 합치기 · 브랜치는 3일 넘기지 않기 ·
  `core/chain.py` `docs/api.md` `1-기획/0-최종 기획서.md` 고칠 땐 먼저 말하기.
- **진행 공유:** 매주 일요일 21시 README 6절에 진행·막힌 점. PR은 상대가 확인. 변경·이슈는 GitHub 이슈로.
- **문장 하나로 말할 수 있어야 한다:** "Trace는 AI를 썼는지 말해주지 않는다. 학생이 자기 과정을 보여주게 한다."
