# 피그마 화면 구성 — 중간발표 · 팀 내부 검토용

> 기준: 지금 앱 v0.1.13 화면 (`Trace 와이어프레임 (2026-10-19).pdf`) + v2.2 다듬기. 색 · 글꼴은 `디자인 기준 v2.html`.
> 가짜 데이터는 `팀 내부 검토 키트` 1절과 같게 (이서연 · 김민준 · 박지호 · 최유나 · 정하준 + 25명).
> ★ = 슬라이드 7 · 8장에 캡처로 들어가는 6개. 나머지는 검토 과업을 끝까지 하려면 필요한 화면.
> **10/31 바뀜 (기획서 v2.2):** 따로 있던 "점검 · 고쳐 쓰기" 단계를 없애고, **출처 보기 화면에 다듬기를 더한다.** 표절 기준 · 참고문헌 확인은 논문용 다음 단계라 피그마에서 뺀다.

## 0. 학생 단계는 그대로 4개

```
기록 → 출처 보기 · 다듬기 → 연결 확인 → 내역서
```

**다듬기는 출처 보기 안에서.** 학생이 다듬을 곳을 먼저 고치고, 고친 뒤의 문장으로 연결을 확인한다. 단계 수가 늘지 않는다.

## 1. 학생 화면 (PC 앱 · 1280 × 800)

### S-0 동의 화면 (처음 기록 시작할 때) — 과업 S1 · S5
- 맨 위: **"감시가 아니에요"** — 원문은 내 PC에만 · 언제든 멈춤 · 보내기 전에 내가 고름 (설문 걸림돌 1위 대응)
- 두 칸: **기록하는 것** (AI 대화 · 복사/붙여넣기 · Word 문서 변화 · 키 입력 *횟수*) / **기록하지 않는 것** (다른 탭 내용 · 메신저 · 키 내용 · 화면)
- 아래: 보관 기간 · "Trace를 쓰기 싫으면 교수님께 손 제출 가능" 한 줄
- 버튼: [동의하고 기록 시작]

### ★ S-1 홈 + 알약 창 — 과업 S1 · S2
- 지금 화면 그대로. 알약 창 상태 3개를 프레임으로: **기록 중** (점 · 시간) / **잠깐 멈춤** (회색 · [다시 시작]) / **마침**

### ★ S-2 출처 보기 · 다듬기 (지금 화면 + 더함) — 과업 S4b · S4c
```
┌ 문장마다 어디서 왔나: AI 답 그대로 3 · 고침 9 · 웹 글 2 · 쓴 과정 기록 없음 0 · 출처 기록 없음 92 ─────────┐
│ 다듬을 곳 3  [모아 보기]                                    다듬음 0 → 3                        │
├──────────────────────────────────────┬───────────────────────────────────────────────────┤
│ 보고서 (다듬을 곳은 옅은 노랑 밑줄)          │ 이 문장은 ChatGPT 10/18 14:20 답을 그대로 붙였어요.          │
│                                      │ 그대로 써도 내역서에 공개돼요. (교수님 규칙: 복붙 감점)       │
│                                      │ [원문 나란히]                                         │
│                                      │ [Word에서 직접 다듬기]   [그대로 둠]                    │
└──────────────────────────────────────┴───────────────────────────────────────────────────┘
  아래 고정: "AI가 대신 고쳐 주지 않아요. 고치는 건 나예요."
```
- 다듬을 곳은 **두 종류뿐**:
  - **AI 답 그대로** → [직접 다듬기] · [그대로 둠] (AI 허용 수업이라 인용을 강요하지 않음)
  - **출처 없는 웹 글** → [인용 달기] · [직접 다듬기]
- 문장마다 상태 3개: **다듬기 전** / **인용 달았음** / **직접 다듬음** — 프레임을 상태별로
- 학생이 GPT에게 "바꿔 줘"로 고친 문장 → 다시 열면 **"아직 AI 답 문장이에요"** (회색 안내, 경고 아님)
- **쓰지 않는 말 · 모양:** "걸린 문장" · 빨간색 · 점수 · 퍼센트 · "표절" · "AI로 고치기" 버튼
- 와이어프레임(10/19)에 남은 **"96% 같음"**, **"직접 씀"**은 가져오지 않는다. 실제 앱은 이미 "일치 / 유사"와 "출처 기록 없음"을 쓴다.

### S-3 연결 확인 — 과업 S3 · 지금 화면
- 이어진 곳 15개 중 **1개가 틀리게 이어진** 데이터를 넣는다 → [아니다]를 누를 수 있어야 함

### ★ S-4 제출 전 확인 · 가리기 — 과업 S4 · S5
- 왼쪽: 내역서에 들어갈 대화 목록 · **친구 전화번호가 있는 대화** → [가리기]
- 오른쪽: **"교수님께 보이는 모습" 미리보기** (여기서 고른 그대로 P-2가 보임). "다듬음 3"이 보이고, **다듬을 곳 목록은 안 보인다**는 게 드러나야 함
- 맨 아래: 보이지 않는 것 한 줄 (가린 내용 · 다른 탭 · 키 내용 · 화면 · 다듬을 곳 목록)
- 버튼: [내역서 만들기] → 완료 화면 (PDF · 교수 링크 복사)

## 2. 교수 화면 (웹 · 1440 × 900 · 로그인 없음)

### P-0 모아 보기 만들기 — 과업 P1
- 입력: 과제 제목 · 메모(허용 범위)
- 결과 **링크 2개를 확실히 다르게**: 🔗 학생에게 보낼 **제출 링크** (공지에 붙이기) / 🔒 교수용 **보기 링크** ("다른 사람에게 보내지 마세요")

### ★ P-1 모아 보기 30명 — 과업 P2
| 학생 | 그대로 쓴 곳 | 고친 곳 | 다듬음 | 쓴 과정 기록 없음 | 직접 타이핑 (이어진 AI 없음) | 쓴 AI |
|---|---|---|---|---|---|---|
- 정렬은 **2개만**: [그대로 쓴 곳 많은 순] (기본) / [쓴 과정 기록 없음 많은 순]
- "쓴 과정 기록 없음"은 회색 빗금 칸, "직접 타이핑"은 흰 칸 → 둘이 절대 같은 모양이면 안 됨
- "다듬음"은 좋은 쪽 숫자 — 강조하지 않고 그냥 숫자로
- 점수 · 등급 · 표절률 · 빨간 표시 없음. 행을 누르면 P-2
- 비교용으로 **PDF 낱장 30개 버전**도 하나 (기존 내역서 PDF 캡처를 줄 세워 둔 프레임) — P2 시간 재기용

### ★ P-2 학생 한 명 내역서 (맨 위 한 줄) — 과업 P3 · P5 · P6
- 맨 위 한 줄 (가장 크게): **그대로 7 · 고침 2 · 쓴 과정 기록 없음 0자 · 다듬음 0** + "✓ 서버 기록과 일치"
- 그 아래 접힌 칸: 학생 설명 2개 · 작업 시간 · 쓴 AI
- 문단 목록 (색 띠): 그대로 / 고침 / 쓴 과정 기록 없음 (빗금) / 직접 타이핑 (흰색) · 다듬은 문장엔 작은 "제출 전 직접 다듬음"
- 김민준 5번째 문단 옆 **작성 모양** (회색 글씨 · 아이콘 없음): "4분 동안 2초 넘게 멈춘 적 없음 · 고침 0회 · 한 번에 1,100자"
- 박지호: "열 때부터 있던 글 1,200자 · 쓴 과정 기록 없음 — 출처를 알 수 없어요"
- 맨 아래 **물어볼 곳** 2~3개 (예: "5번째 문단은 어떻게 썼나요?")
- 와이어프레임의 **"그대로 (96%)"**는 가져오지 않는다 → "그대로"만

### ★ P-3 나란히 보기 — 과업 P4
- 왼쪽 보고서 문장 · 오른쪽 AI 답 원문, 같은 부분 같은 색
- 위: 질문 원문 · 도구 · 시각 · "기록과 일치"
- 아래: 들어온 길 (14:21 ChatGPT에서 복사 → 14:22 Word 3문단에 붙여넣기 → 14:25 한 단어 고침)

## 4. 화면마다 원칙 확인 (검토 키트 체크리스트)

- [ ] 점수 · 퍼센트 · 표절률 · 등급처럼 보이는 것이 없다 (와이어프레임의 "96%"를 가져오지 않았나)
- [ ] "쓴 과정 기록 없음"과 "직접 타이핑"이 다르게 보인다 (S-2 · P-1 · P-2)
- [ ] 다듬을 곳이 "걸림" · 빨간색 · 경고로 보이지 않는다 · AI가 대신 고치는 버튼이 없다 (S-2)
- [ ] 다듬을 곳 목록은 교수에게 안 간다는 게 학생에게 보인다 (S-4)
- [ ] 작성 모양이 경고처럼 보이지 않는다 (P-2)
- [ ] 학생 화면이 감시처럼 보이지 않는다 (S-0 · S-1)

2. S-0 · S-4 · P-0 · P-3
3. S-1 · S-3은 지금 화면 캡처 그대로
