# 피그마 화면 구성 — 중간발표 · 팀 내부 검토용

> 기준: 지금 앱 v0.1.13 화면 (`Trace 와이어프레임 (2026-10-19).pdf`) + v2.1 새 화면. 색 · 글꼴은 `디자인 기준 v2.html`.
> 가짜 데이터는 `팀 내부 검토 키트` 1절과 같게 (이서연 · 김민준 · 박지호 · 최유나 · 정하준 + 25명).
> ★ = 슬라이드 7 · 8장에 캡처로 들어가는 6개. 나머지는 검토 과업을 끝까지 하려면 필요한 화면.

## 0. 학생 단계가 하나 늘어난다

```
지금:  기록 → 출처 보기 → 연결 확인 → 내역서
v2.1:  기록 → 출처 보기 → 연결 확인 → 점검 · 고쳐 쓰기 → 내역서
```

**점검은 연결 확인 다음.** 연결이 틀리면 엉뚱한 원문과 비교하게 되므로, 학생이 연결을 바로잡은 뒤에 점검한다. 홈 · 과제 상세의 4단계 표시를 5단계로 바꾼다.

## 1. 학생 화면 (PC 앱 · 1280 × 800)

### S-0 동의 화면 (처음 기록 시작할 때) — 과업 S1 · S5
- 맨 위: **"감시가 아니에요"** — 원문은 내 PC에만 · 언제든 멈춤 · 보내기 전에 내가 고름 (설문 걸림돌 1위 대응)
- 두 칸: **기록하는 것** (AI 대화 · 복사/붙여넣기 · Word 문서 변화 · 키 입력 *횟수*) / **기록하지 않는 것** (다른 탭 내용 · 메신저 · 키 내용 · 화면)
- 따로 켜고 끄는 것: "기록 중 연 웹 페이지 본문으로 점검하기" (기본 끔 · 2단계 기능)
- 아래: 보관 기간 · "Trace를 쓰기 싫으면 교수님께 손 제출 가능" 한 줄
- 버튼: [동의하고 기록 시작]

### ★ S-1 홈 + 알약 창 — 과업 S1 · S2
- 지금 화면 그대로. 알약 창 상태 3개를 프레임으로: **기록 중** (빨간 점 · 시간) / **잠깐 멈춤** (회색 · [다시 시작]) / **마침**
- 바꿀 것: 과제 카드의 단계 표시 4 → 5칸

### S-2 출처 보기 — 지금 화면
- 바꿀 것 2개 (원칙 체크리스트에 걸림):
  - 오른쪽 **"96% 같음"** → **"한 단어 다름"**처럼 사실 문장으로 (퍼센트가 점수처럼 보임)
  - 위쪽 칸 이름 **"직접 씀"** → **"직접 타이핑 (이어진 AI 없음)"** ("직접 썼다"고 단정하지 않기)

### S-3 연결 확인 — 과업 S3 · 지금 화면
- 이어진 곳 15개 중 **1개가 틀리게 이어진** 데이터를 넣는다 → [아니다]를 누를 수 있어야 함

### ★ S-4 점검 · 고쳐 쓰기 (새로) — 과업 S4b · S4c
```
┌ 걸린 문장 3 · 참고문헌 1 ───┐┌ 내 문장 ─────────────────┬ 원문 (ChatGPT · 10/18 14:20) ─┐
│ ① 9어절 연속 같음 · 인용 없음 ││ [같은 부분 노랑 표시]      │ [같은 부분 노랑 표시]         │
│ ② 단어만 바꿈 (3곳)          │├──────────────────────────┴──────────────────────────────┤
│ ③ 능동 → 피동만 바꿈          ││ 기준: 연속 일치 9어절 · 기본값 6어절 (검사 도구 관행) ⓘ      │
│ ─────────────              ││ 교육부 연구윤리 지침 "가. 출처 없이 그대로 활용"에 해당할 수 있음 │
│ 참고문헌 5개 중 1개           ││                                                     │
│   Crossref에서 찾을 수 없음   ││ [인용 달기]   [Word에서 다시 쓰고 → 다시 점검]   [이대로 둠] │
└───────────────────────────┘└─────────────────────────────────────────────────────┘
  아래 고정: 점검 후 고침 0 → 2   ·   "AI가 대신 고쳐 주지 않아요. 고치는 건 나예요."
```
- 문장마다 상태 3개: **처리 전** / **인용 달았음** / **다시 씀 (다시 점검 통과)** — 프레임을 상태별로 만든다
- ②는 원문과 바뀐 단어 3곳을 짝으로 (예: "중요하다 ↔ 핵심적이다")
- ⓘ 누르면: 기준 이름 · 출처 (지침 · Barrón-Cedeño 2013) · "점수가 아니라 원문과 비교한 사실"
- 참고문헌 칸: 찾지 못한 1개를 누르면 "제목 · 저자 · 연도로 Crossref에서 찾지 못했어요. 실제로 있는 문헌인지 확인해 주세요." + [고침] [이대로 둠]
- **넣지 않는 것:** 점수 · 퍼센트 · 빨간 경고 · "AI로 고치기" 버튼

### ★ S-5 제출 전 확인 · 가리기 — 과업 S4 · S5
- 왼쪽: 내역서에 들어갈 대화 목록 · **친구 전화번호가 있는 대화** → [가리기]
- 오른쪽: **"교수님께 보이는 모습" 미리보기** (S-5에서 고른 그대로 P-2가 보임)
- 맨 아래: 보이지 않는 것 한 줄 (가린 내용 · 다른 탭 · 키 내용 · 화면)
- 버튼: [내역서 만들기] → 완료 화면 (PDF · 교수 링크 복사)

## 2. 교수 화면 (웹 · 1440 × 900 · 로그인 없음)

### P-0 모아 보기 만들기 — 과업 P1
- 입력: 과제 제목 · 메모(허용 범위)
- 결과 **링크 2개를 확실히 다르게**: 🔗 학생에게 보낼 **제출 링크** (공지에 붙이기) / 🔒 교수용 **보기 링크** ("다른 사람에게 보내지 마세요")

### ★ P-1 모아 보기 30명 — 과업 P2
| 학생 | 그대로 쓴 곳 | 고친 곳 | 점검 후 고침 | 쓴 과정 기록 없음 | 직접 타이핑 (이어진 AI 없음) | 쓴 AI |
|---|---|---|---|---|---|---|
- 정렬은 **2개만**: [그대로 쓴 곳 많은 순] (기본) / [쓴 과정 기록 없음 많은 순]
- "쓴 과정 기록 없음"은 회색 빗금 칸, "직접 타이핑"은 흰 칸 → 둘이 절대 같은 모양이면 안 됨
- 점수 · 등급 · 빨간 표시 없음. 행을 누르면 P-2
- 비교용으로 **PDF 낱장 30개 버전**도 하나 (기존 내역서 PDF 캡처를 줄 세워 둔 프레임) — P2 시간 재기용

### ★ P-2 학생 한 명 내역서 (맨 위 한 줄) — 과업 P3 · P5 · P6
- 맨 위 한 줄 (가장 크게): **그대로 7 · 고침 2 · 점검 후 고침 0 · 쓴 과정 기록 없음 0자** + "✓ 서버 기록과 일치"
- 그 아래 접힌 칸: 학생 설명 2개 · 작업 시간 · 쓴 AI
- 문단 목록 (색 띠): 그대로 / 고침 / 쓴 과정 기록 없음 (빗금) / 직접 타이핑 (흰색)
- 김민준 5번째 문단 옆 **작성 모양** (회색 글씨 · 아이콘 없음): "4분 동안 2초 넘게 멈춘 적 없음 · 고침 0회 · 한 번에 1,100자"
- 박지호: "열 때부터 있던 글 1,200자 · 쓴 과정 기록 없음 — 출처를 알 수 없어요"
- 맨 아래 **물어볼 곳** 2~3개 (예: "5번째 문단은 어떻게 썼나요?")
- 기존 교수 링크 화면의 **"그대로 (96%)"도 사실 문장으로** 바꾼다

### ★ P-3 나란히 보기 — 과업 P4
- 왼쪽 보고서 문장 · 오른쪽 AI 답 원문, 같은 부분 같은 색
- 위: 질문 원문 · 도구 · 시각 · "기록과 일치"
- 아래: 들어온 길 (14:21 ChatGPT에서 복사 → 14:22 Word 3문단에 붙여넣기 → 14:25 한 단어 고침)

## 4. 화면마다 원칙 확인 (검토 키트 체크리스트)

- [ ] 점수 · 퍼센트 · 등급처럼 보이는 것이 없다 → **S-2 · P-2의 "96%"를 꼭 고친다**
- [ ] "쓴 과정 기록 없음"과 "직접 타이핑"이 다르게 보인다 (S-2 · P-1 · P-2)
- [ ] 점검 결과 옆에 기준 이름이 있다 · AI가 대신 고치는 버튼이 없다 (S-4)
- [ ] 작성 모양이 경고처럼 보이지 않는다 (P-2)
- [ ] 학생 화면이 감시처럼 보이지 않는다 (S-0 · S-1)

## 만드는 순서 (내일 ~ 4일째)

1. **S-4 점검**, **P-1 모아 보기**, **P-2 한 줄** 먼저 — 새 화면이고 발표 핵심
2. S-0 · S-5 · P-0 · P-3
3. S-1 · S-2 · S-3은 지금 화면 캡처에 바꿀 것만 덧칠
4. 프로토타입 연결 → 검토 1회차
