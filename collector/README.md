# Trace 수집기

컴퓨터를 켜두면 **뒤에서 조용히 돌면서, 어떤 프로그램을 보고 있었는지 적는** 프로그램입니다.

지금은 **1단계**입니다 — 화면에 찍기만 하고 아직 저장하지 않습니다.

---

## 파일이 뭐가 뭔지

| 파일 | 하는 일 | 누가 |
|---|---|---|
| `collector.py` | 1초마다 확인하고 바뀌면 한 줄 찍는다 | 같이 씀 |
| `platform_mac.py` | 맥에서 "지금 무슨 프로그램?"을 알아낸다 | A (맥) |
| `platform_win.py` | 윈도우에서 같은 일을 한다 | **B (윈도우) — 아직 비어 있음** |

`collector.py` 는 지금이 맥인지 윈도우인지 보고 알아서 맞는 파일을 불러옵니다.
그래서 **두 사람이 각자 자기 것만 만들면 됩니다.**

---

## 처음 한 번만 (준비)

터미널(검은 창)을 열고 **한 줄씩** 칩니다.

### 맥

```bash
conda create -n trace python=3.11 -y
```
```bash
conda activate trace
```
```bash
pip install pyobjc-framework-Cocoa
```

### 윈도우 (Anaconda Prompt 에서)

```bash
conda create -n trace python=3.11 -y
```
```bash
conda activate trace
```
```bash
pip install pywin32 psutil
```

---

## 실행

```bash
conda activate trace
```
```bash
cd ~/dev/trace/collector
```
```bash
python collector.py
```

> 윈도우는 `cd %USERPROFILE%\dev\trace\collector`

이렇게 뜹니다. **창을 바꿔 보세요.**

```
  Trace 수집기를 시작합니다.
  지금 컴퓨터: Darwin
  ──────────────────────────────────────
  14:30:02   Google Chrome
  14:30:15   Microsoft Word
  14:30:41   Google Chrome
```

멈추려면 **Control + C**.

---

## 맥은 창 제목이 안 나옵니다

프로그램 이름만 나오고 창 제목은 비어 있습니다.
맥은 다른 프로그램의 창 제목을 읽으려면 **시스템 설정 → 개인정보 보호 → 화면 기록** 권한이 필요하기 때문입니다.

윈도우는 권한 없이도 창 제목까지 나옵니다. 그래서 **윈도우 쪽 기록이 더 자세합니다.**

1단계에서는 프로그램 이름만으로 충분합니다.

## 만들면서 겪은 문제 (설명할 수 있어야 하는 것)

**증상** — 창을 바꿔도 직전 프로그램 이름이 계속 찍혔다. 한 박자씩 늦었다.

**원인** — 맥은 "지금 어떤 프로그램이 활성이다" 같은 소식을 우리 프로그램의
**우편함**에 넣어 둔다. 우리가 우편함을 열어보지 않으면, 맥에게 물어봐도
예전에 받아둔 옛날 소식을 그대로 돌려준다.

**해결** — 읽기 직전에 우편함을 0.05초만 열었다 닫는다.
`platform_mac.py` 의 `NSRunLoop...` 한 줄이 그것이다.

| | 결과 |
|---|---|
| 그냥 읽기 | Finder, Finder, Claude, Finder — 계속 한 박자 늦음 |
| 우편함 열고 읽기 | Finder, Claude, Finder, Claude — 정확 |

윈도우에는 이 문제가 없다. `GetForegroundWindow()` 는 물어보면 바로 지금 값을 준다.
