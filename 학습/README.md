## 왜 하나

지금 상태를 솔직하게 적으면 이렇습니다.

```
만들어진 것    수집기 · 해시 체인 · 서버 · DB · React 화면 · 확장
설명할 수 있는 것    ?
```

**AI를 쓴 게 잘못이 아닙니다.** 10주에 2명이 이만큼 만들려면 그 방법이 맞았습니다.
문제는 다른 데 있습니다.

| 언제 | 무슨 일이 생기나 |
|---|---|
| **데스크 크리틱** | "이거 어떻게 동작해요?" → 답 못 하면 그 자리에서 끝 |
| **10/7 관통** | 안 되면 스스로 못 고침. 붙어 있는 사람을 기다려야 함 |
| **7주차 증명서** | 목업을 코드로 옮기려면 지금 코드를 읽을 줄 알아야 함 |

## 5주 계획

### 1주차 — 말부터 ([자세히](1주차-말부터.md))

용어를 모르면 어떤 설명도 안 들립니다. 먼저 말을 잡습니다.

| 일 | 무엇 | 끝나면 말할 수 있어야 |
|---|---|---|
| 1 | 프로그램 · 서버 · 클라이언트 | "서버가 뭐예요?" |
| 2 | API · JSON | "수집기가 서버에 뭘 보내요?" |
| 3 | 데이터베이스 · 표 | "기록이 어디에 저장돼요?" |
| 4 | 프론트 · 백엔드 | 우리 구조도를 **손으로 그리기** |
| 5 | 복습 — 팀원에게 설명해 보기 | |

### 2주차 — 파이썬 읽기

**쓰는 게 아니라 읽는 게 목표**입니다.

| 일 | 무엇 | 교재 |
|---|---|---|
| 1 | 변수 · 값의 종류 (글자 · 숫자 · 참거짓) | |
| 2 | 리스트 · 딕셔너리 ← **JSON 과 똑같습니다** | |
| 3 | 함수 — 넣으면 나온다 | |
| 4 | `if` · `for` — 조건과 반복 | |
| 5 | **`classify.py` 61줄 전부 읽기** | 앱 이름 → 분류 |

### 3주차 — 우리 수집기

| 일 | 무엇 | 교재 |
|---|---|---|
| 1 | `import` — 파일이 서로를 부르는 법 | |
| 2 | **`platform_mac.py`** 함수 4개 | 창 · 유휴 · 권한 |
| 3 | `while` — 1초마다 도는 루프 | `collector.py` 의 `_tick()` |
| 4 | 이벤트 한 줄이 만들어지는 과정 따라가기 | |
| 5 | **직접 고쳐 보기** — 찍히는 줄에 뭔가 하나 더하기 | |

### 4주차 — 해시와 체인 ★ 발표의 핵심

여기가 제일 중요합니다. **우리 기술의 심장**입니다.

| 일 | 무엇 |
|---|---|
| 1 | 해시가 뭔가 — 직접 쳐 보기 |
| 2 | 왜 **앞 해시를 재료에 넣나** |
| 3 | **`chain.py` 77줄 전부 읽기** |
| 4 | **직접 깨뜨려 보기** — 한 글자 바꾸고 어디서 걸리는지 |
| 5 | 루트 해시 · 증명하는 것과 **못 하는 것** |

### 5주차 — 서버 · DB · 화면

| 일 | 무엇 |
|---|---|
| 1 | HTTP · GET/POST · 상태코드(200 · 401 · 404) |
| 2 | Flask 라우트 — `app.py` 에서 **3개만** |
| 3 | DB — SQL 을 **직접 쳐 보기** |
| 4 | React — `App.jsx` 60줄 |
| 5 | **전체 흐름 한 장으로 그리기** + 발표 예상 질문 |
