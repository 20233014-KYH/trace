# 실습 — 지금까지 만든 것 만져보기 (맥, 약 20분)

터미널 창 **두 개**를 씁니다. 하나는 서버, 하나는 나머지.

> 명령은 전부 `3-코드` 폴더에서 칩니다.
> ```
> cd ~/dev/trace/3-코드
> conda activate trace
> ```
> 프롬프트 맨 앞이 `(trace)` 인지 확인하세요. 아니면 다 안 됩니다.

## 4. ★ 조작해 보기 — 이게 핵심입니다

기록 파일을 **메모장으로 고치면 어떻게 되는지** 직접 해봅니다.

```bash
cp data/events-*.jsonl data/조작.jsonl
open -e data/조작.jsonl
```

텍스트편집기가 열립니다. **아무 `"app"` 값 하나를 다른 이름으로 바꾸고 저장**하세요.
(예: `"app": "메모"` → `"app": "Microsoft Word"`)

그다음:

```bash
python - <<'EOF'
import json, sys
sys.path.insert(0, ".")
from core import chain as C
줄들 = [json.loads(l) for l in open("data/조작.jsonl", encoding="utf-8") if l.strip()]
ok, 어디 = C.verify(줄들)
print("정상" if ok else f"❌ 어긋남 — 처음 걸린 이벤트: {어디}")
EOF
```

```
❌ 어긋남 — 처음 걸린 이벤트: evt_000002
```

**한 글자만 바꿔도 잡힙니다.** 그리고 그 뒤 이벤트의 해시가 전부 달라져서 루트도 바뀝니다.

### 서버는 더 세게 잡습니다

```bash
python server/test_contract.py
```

```
✅ 5 batch 조작 탐지    evt_000021 의 입력 30 → 999 → verified=False
✅ 6 봉인 (조작 세션)    HTTP 409 · chain_mismatch
```

서버가 **자기가 받은 이벤트로 다시 계산해서** PC 가 보낸 해시와 맞춰 봅니다.
학생 PC 에서 고쳐도, 서버에서 고쳐도 **어느 한쪽만으로는 못 속입니다.**

## 5. 로그인 만져보기

```bash
python server/test_auth.py
```

검사 14개가 지나갑니다. 직접 해보려면:

```bash
curl -s -X POST localhost:5000/api/auth/signup \
  -H "Content-Type: application/json" \
  -d '{"email":"나@test.kr","password":"비밀번호12345","name":"용현"}'

curl -s -X POST localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"나@test.kr","password":"비밀번호12345"}'
```

돌아온 `token` 을 넣어서:

```bash
curl -s localhost:5000/api/me -H "Authorization: Bearer 여기에토큰"
```

**비밀번호가 어떻게 저장돼 있는지 직접 보기:**

```bash
sqlite3 server/trace.db "SELECT email, substr(password_hash,1,30) FROM users"
```

```
나@test.kr|scrypt:32768:8:1$VKj...
```

원문이 아니라 **되돌릴 수 없는 값**으로 저장됩니다.

## 6. Learn 모드 — 팀원이 만든 화면

지금까지는 **Proof** 모드였습니다. Learn 은 같은 기록에 **맥락**(AI 질문·답변 발췌·참고 페이지)을 얹고 **AI 리포트**를 냅니다.

### 화면부터 보기 (서버 없이)

```bash
cd web && npm run dev
```

`http://localhost:5173` → **[Learn 샘플]**

| 탭 | 무엇 |
|---|---|
| **타임라인 + 맥락** | 레인에 '학습 흐름' 한 줄 추가. 마커를 누르면 오른쪽에 **오류 → 질문 → 답변 발췌 → 그 뒤에 한 일** |
| **Learning Report** | 타일 4개 + AI 5항목 (주요 학습 내용 · 어려움 · 학습 과정 · 학습 포인트 · 추가 학습) |
| **이벤트 원본** | 체인 그대로 |

오른쪽 아래 **알약 위 질문칸**도 눌러 보세요. 채팅 패널이 위로 펼쳐집니다.

### 진짜 서버로 (AI 키 없이)

창 A 를 `LLM_PROVIDER=fake` 로 켜면 **가짜 리포트**가 나옵니다. 화면 확인은 이걸로 충분합니다.

```bash
LLM_PROVIDER=fake python server/app.py
```

수집기를 **learn 모드**로:

```bash
python collector/collector.py --mode learn --work W-LEARN
```

끝나면 React 화면 위쪽에 **세션 id 를 넣고 [서버]**.

> 실제 AI 리포트를 보려면 `cp ../.env.example ../.env` 후 `OPENAI_API_KEY` 만 채우세요.

### Proof 세션에는 AI 가 안 붙습니다

```bash
curl -s localhost:5000/api/sessions/어떤proof세션id/context
```
```json
{"error":"proof_session","message":"Proof 세션에는 맥락·AI 를 쓰지 않습니다"}
```

**403 이 정상입니다.** 한 세션은 한 모드입니다.
