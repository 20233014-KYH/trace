맥 설치판이 나왔다 (Apple 칩 · macOS 11 이상) — 윈도우처럼 내려받아 쓴다.

- 로그인 · 가입 → 처음 한 번 안내 → 홈 · 새 과제 · 과제 상세 [기록 시작] → 출처 보기 · 연결 확인 · 내보내기 (교수 링크 · PDF)
- 맥: .dmg 를 열어 Trace 를 응용 프로그램으로 끌어 넣기 · 처음 열 때 "그래도 열기" (애플 개발자 등록 전)
- 맥: 기록 준비 점검이 확장 · 앱 · Word 를 찾고, 키 입력 횟수용 '입력 모니터링' 권한을 알려 줌
- 맥: 앱이 30초 넘게 걸리던 시작이 1초로 · 기록 창이 Dock 에 겹치지 않음 · 창 □ 되돌리기
- 기록은 윈도우 %LOCALAPPDATA%\Trace · 맥 ~/Library/Application Support/Trace — 새 버전을 깔아도 남는다
- 윈도우: 코드 서명 전이라 "Windows의 PC 보호" → 추가 정보 → 실행
