# 인터넷 서버 이용 가이드 (10/7~)

이제 서버가 인터넷에 있습니다. **김용현 PC를 켜 둘 필요 없이** 아무 컴퓨터에서나 기록을 보낼 수 있습니다.

| | |
|---|---|
| 서버 주소 | `https://trace-server-8aa0.onrender.com/api` |
| 상태 확인 | <https://trace-server-8aa0.onrender.com/api/health> → `"ok":true, "storage":"db"` 면 정상 |
| 저장하는 곳 | Supabase (서울) — 10/7 첫 연결 기록도 여기 있음 |

---

## 기록기 연결 (윈도우)

10/7에 만든 `%USERPROFILE%\trace-config.json` 을 그대로 씁니다. **서버 주소 한 줄만** 바꾸면 됩니다.

**1) 최신 코드 받기**
```
git pull
```

**2) 설정 파일 열기**
```
notepad %USERPROFILE%\trace-config.json
```
(파일이 없으면 먼저 `copy collector\config.json %USERPROFILE%\trace-config.json`)

**3) `"server"` 줄을 이렇게 바꾸고 저장**
```
"server": "https://trace-server-8aa0.onrender.com/api",
```
- 끝에 `/api` 를 꼭 붙이세요.
- 줄 끝 쉼표(`,`)는 지우지 마세요.
- `collector\config.json` 은 고치지 마세요. 깃에 올라가는 파일입니다.

**4) 서버 깨우기**
브라우저에서 <https://trace-server-8aa0.onrender.com/api/health> 를 열고, 글자가 뜰 때까지 기다립니다 (최대 1분).

**5) 기록기 켜기** (`3-코드` 폴더에서 · `--dry-run` 없이)
```
.venv\Scripts\python.exe collector\collector.py --config %USERPROFILE%\trace-config.json --work W-과제이름
```
첫 줄에 `server=https://trace-server-8aa0…/api` 가 보이면 됩니다. `(dry-run)` 이 보이면 안 됩니다.

**6) 끝낼 때 `Ctrl+C`**
마지막에 `작업 기록이 완료되었습니다 · 서버 기록과 일치합니다` 와 `체인 N건 · 루트 xxxx…` 가 나오면 서버까지 잘 들어간 겁니다.
(PR #29 전 기록기는 `봉인 검증됨` 으로 나옵니다. 같은 뜻입니다.)

## 이런 글이 뜨면

| 화면에 뜬 글 | 뜻 | 할 일 |
|---|---|---|
| `서버 응답 없음 → queue.jsonl 에 보관` | 서버가 자다 깨는 중 | **그냥 두세요.** 10초마다 다시 보내고, 기록은 안 잃습니다 |
| `거절됨 HTTP 4xx/5xx` | 서버가 받기를 거부함 | 화면을 캡처해서 김용현에게 |
| `서버 기록과 다릅니다` (옛 문구 `봉인 검증 실패`) | 서버에서 다시 계산한 값이 다름 | 화면 캡처 + `data\` 폴더의 그 세션 파일을 보관 |

## 알아둘 것

- **무료 서버라서 15분 동안 안 쓰면 잠듭니다.** 첫 요청은 1분쯤 걸립니다. 그래서 4)번처럼 미리 깨워 두세요.
- **DB 주소와 비밀번호는 Render 설정에만 있습니다.** 채팅·깃·캡처에 절대 올리지 마세요. 필요하면 김용현이 직접 넣습니다.
- `trace-config.json` 과 **개인 과제 원문**(Word 파일, ChatGPT 공유 링크 등)은 저장소에 올리지 않습니다.
- **Render 정기 점검:** 10/14(화) 10:00 KST. 이 시간에는 잠깐 안 될 수 있습니다.
- 서버는 **싱가포르**에서 돌아갑니다. 실제 학생 기록을 받기 전에는 국외 이전 동의 문구가 있어야 합니다. 지금은 우리 시험 기록만 넣으세요.
- 웹 화면(`web/`)은 아직 내 PC의 서버(127.0.0.1:5000)만 봅니다. 인터넷 서버에 붙이는 건 다음 작업입니다.

## 서버 코드를 바꾸면

`main` 에 합쳐지면 Render가 **자동으로 다시 배포**합니다 (1분쯤). 설정은 저장소 맨 위 `render.yaml` 에 다 있고, 자세한 내용은 `server/README.md` 의 「배포」 절을 보세요.
