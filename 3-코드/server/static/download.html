설치 순서 (Windows 10 · 11)

  1. 내려받은 Trace-Setup.exe 를 엽니다.
  2. Windows의 PC 보호 창이 뜨면 추가 정보 → 실행. 아직 코드 서명을 하지 않은 시험판이라 뜹니다.
  3. 설치가 끝나면 Trace 가 열립니다. 로그인하거나 처음이면 가입합니다.
  4. 과제를 만들고 과제 화면에서 기록 시작. 화면 구석에 기록 창이 뜨면 기록 중입니다.
  5. 과제를 끝내면 출처 보기 → 연결 확인 → 내보내기에서 교수 링크나 PDF 로 냅니다.

기록기는 키를 몇 번 눌렀는지만 세고 무엇을 쳤는지는 남기지 않습니다. 그래도 백신이 막으면 그 알림을 캡처해 알려 주세요.

설치 순서 (macOS 11 이상 · Apple 칩)

  1. 내려받은 Trace-mac.dmg 를 열고 Trace 를 응용 프로그램 으로 끌어 넣습니다. dmg 창에서 바로 열지 말고 꼭 옮긴 뒤 여세요 (안 그러면 권한이 제대로 붙지 않습니다).
  2. 응용 프로그램에서 Trace 를 엽니다. 'Trace'을(를) 열지 않음 창이 뜨면 완료 → 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 그래도 열기 → 암호 입력 → 다시 엽니다. 애플 공증 전 시험판이라 처음 한 번 뜹니다.
  3. 로그인하거나 처음이면 가입합니다. 과제 화면에서 기록 시작.
  4. 시스템 설정 → 개인정보 보호 및 보안에서 Trace 를 켭니다 → Trace 를 ⌘Q 로 끄고 다시 엽니다.
    손쉬운 사용 — Claude · ChatGPT 데스크톱 앱 대화와 창 제목
    입력 모니터링 — 키 입력 횟수
    안 켜도 창 · 복사 · 웹 AI 대화(크롬 확장) 기록은 남습니다.
  5. Word · PowerPoint 를 처음 쓸 때 "Trace 가 Microsoft Word 를 제어하려고 합니다" → 허용. 글이 바뀌는 과정이 남습니다.

앱 글은 화면낭독기와 같은 길로 읽고, 화면을 찍지 않습니다. 원문은 이 Mac 에만 남습니다. 인텔 칩 맥은 아직 지원하지 않습니다.

브라우저 AI 기록 (크롬 확장 · 선택)

  1. 확장 내려받기 (.zip) → 압축을 풉니다.
  2. 크롬 주소창에 chrome://extensions → 오른쪽 위 개발자 모드 켜기.
  3. 압축해제된 확장 프로그램을 로드합니다 → 푼 폴더를 고릅니다.

ChatGPT · Claude · Gemini 웹에서 묻고 받은 글이 기록됩니다 (Trace 기록이 켜져 있을 때만). 웹스토어 등록 전 시험판이라 직접 불러옵니다.
