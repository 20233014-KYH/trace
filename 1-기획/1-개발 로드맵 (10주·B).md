## 5. 위험 — 내 쪽에서 미리 막을 것

| 위험 | 대응 |
|---|---|
| React를 5주차에 처음 만짐 | 1주차에 1시간, 3주차에 1시간 더. `lanes()`는 순수 SVG 문자열이라 컴포넌트 전환이 쉽다 |
| 확장이 7주차에 몰림 | ~~5주차에 manifest 먼저~~ 1주차에 뼈대 완료 (9/20). 7주차엔 정확도만 |
| 기록이 "감시"로 읽힘 | 항목별 토글(첫 실행 동의 화면) · **제출 전 가리기** · 교수 자동 공유 경로 없음 · 판정·점수 없음 |
| 기록한 AI 대화에 API 키·개인정보가 섞임 | 요약·공유 전에 자동으로 가림 (미구현 · 방향과 무관하게 필요) |
| 키 훅이 "키로거"로 오해 | `keys.py` 파일 자체를 보여준다. 횟수만 센다는 걸 코드로 |
| 관통 1(10/7) 밀림 | 상대 서버가 안 되면 `dev_receiver.py` 를 계약대로 써서 자기 쪽은 끝냄. **터널은 그 전에 준비** (`127.0.0.1` 은 상대 PC에서 안 닿음) |
| 문장 유사도 정확도가 안 나옴 | 10월 1주에 먼저 테스트한다. 10개 중 8개에 못 미치면 **문단 단위로 축소** (기획서 12절) |
