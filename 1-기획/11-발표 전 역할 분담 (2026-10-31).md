# 중간발표 전 역할 분담 (4일)

> 기준 문서: `9-중간발표 슬라이드 뼈대` · `2-디자인/피그마 화면 구성` · `2-디자인/팀 내부 검토 키트`
> 원칙: **화면을 만든 사람은 검토 때 지켜보기만, 과업은 안 만든 사람이 한다.** → 학생 화면과 교수 화면을 나눠 만들면 서로 검토가 된다.

## 누가 무엇을

| | 김용현 | 박상진 |
|---|---|---|
| **피그마** | 교수 화면 2개: ★P-1 **내역서 화면** (5명 분) · ★P-2 **내역서 상세 (나란히 보기)** + 상진의 S-2 다듬기 화면 같이 다듬기 (만들기는 상진 · 검토 전까진 의견만) | 학생 화면 5개: S-0 동의 · ★S-1 홈 + 알약 · ★**S-2 출처 보기 · 다듬기** · S-3 연결 확인 · ★S-4 제출 전 가리기 |
| **프로토타입 연결** | P-1 ↔ P-2 | S-0 → S-1 → S-2 (다듬음 0→3) → S-3 → S-4 |
| **검토 때 하는 과업** | 상진 화면으로 **S1 ~ S5** (S4b · S4c 포함) | 용현 화면으로 **P1 ~ P5** |
| **슬라이드** | 1 표지 · 4 콘셉트 · 5 기능 · 범위 · 8 교수 화면 + 검토 결과 · 9 시스템 · 10 ERD · 11 개발 계획 | 2 문제 · 3 인사이트 (설문 그림) · 6 User Flow · 7 학생 화면 |
| **그 밖** | PDF 합치기 · 디자인 맞추기 · 피그마 링크 제출 | 한글 직접 쓰기 vs 옮겨 치기 비교 (작성 모양 근거 · 되면 11장 한 줄) |

- 그림 4개(User Flow · 시스템 구조 · ERD · 설문)는 이미 있음 → `2-디자인/발표 그림/`
- 색 · 글꼴은 둘 다 `2-디자인/디자인 기준 v2.html`
- 가짜 데이터는 키트 1절 그대로 (이서연 · 김민준 · 박지호 · 최유나 · 정하준)

| 날 | 김용현 | 박상진 | 같이 |

- 검토 회차마다 키트 5절 문제 목록 · 6절 비교표(문제 수 · P1 2명 고르는 시간 · P2 10초)를 채운다 → 8장 근거
- 고치기 **전 · 후 캡처 한 쌍**은 꼭 남긴다 (8장)

## 발표 (제안)

- **발표: 김용현** (5분) · **시연 · 질의 보조: 박상진** (학생 화면 · 기록기 질문)
- 연습 때 시간이 넘치면 줄이는 순서: 3장 → 5장 → 11장. **6 ~ 8장(UI/UX 25점)은 줄이지 않는다.**
