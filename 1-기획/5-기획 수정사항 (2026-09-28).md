## 0. 한 줄 요약

**Learn/Proof 두 모드를 없애고, 기록은 하나로 합친다.** 과제하는 동안 작성 과정과 AI 사용(질문·답·붙인 위치)을 자동으로 기록하고, 과제가 끝나면 과제 유형(AI 금지/허용)에 맞는 **요약 1장**을 낸다. 의심받을 때는 **공유 링크**로 전체 과정을 보여준다. **판정·점수는 만들지 않는다.**

## 1. 왜 바뀌었나

| 기존 | 문제 (교수 피드백·검토 결과) | 바뀐 방향 |
|---|---|---|
| Learn Mode: AI가 학습 과정을 분석해 리포트·Side Chat 제공 | 교육 도구 영역이라 초점이 흐림. "누가 이걸 보냐"에 답이 없음 | **삭제.** 맥락 수집(AI 질문·답)만 살려 내역서 재료로 씀 |
| "모든 협업 과정을 추적" 요구 | 범위가 너무 넓고, 구글 문서·GitHub가 이미 기록함 | 실시간 동시 편집은 추적하지 않음. **각자 기록 → 과제 단위로 합침** |
| Proof: 내용을 전혀 안 읽고 횟수·해시만 | AI 답을 **어떻게 고쳐 썼는지** 보여줄 수 없음 | **기록은 하나**(내용 포함). 출력만 과제 유형별로 다름 |
| 증명서(A4)·OTS 앵커 | 이번 학기에 과함 | **요약 1장 PDF**로 대체. 외부 시간 도장(OTS)은 나중 |

### 문제 정의 (제안서 1장)
> 대학생은 과제 제출 후 AI 사용을 의심받거나 밝혀야 하는 상황에서, 작성 과정이 기록으로 남지 않기 때문에, 자기가 직접 한 일을 보여주지 못하는 어려움을 겪는다.

### 서비스 개념 (제안서 3장)
> Trace는 대학생이 과제의 작성 과정과 AI 사용 내역을 밝히는 일을, 손 정리 없이 자동 기록으로 하도록 돕는 PC 프로그램·웹이다.

### 대상 사용자
모든 학생이 아니다. **AI 탐지기에 억울하게 의심받았거나 받을까 불안한 학생, 자기 몫을 보여주고 싶은 학생, AI 허용 과제에서 사용 내역을 내야 하는 학생.** 교수는 요약 1장을 받고, 의심될 때만 링크를 연다.

## 2. 바뀌지 않는 원칙 (코드 곳곳에 지켜야 함)

1. **판정하지 않는다.** "AI 확률", 퍼센트 유사도, 등급, 점수를 화면·PDF·API 어디에도 내지 않는다. 사실(횟수·시각·출처·원문)만.
2. **기록 없는 부분은 "직접 씀"이 아니라 "출처 기록 없음"으로 표시한다.** Trace는 휴대폰·다른 PC에서 쓴 AI를 못 잡는다. 없는 걸 있다고, 있는 걸 없다고 단정하지 않는다.
3. **학생이 켜고, 학생이 확인하고, 학생이 제출한다.** 교수에게 자동으로 가는 경로는 없다.
4. **개인정보:** 과제 시작을 눌렀을 때만, 과제에 필요한 것만 기록한다. 학생이 확인한 뒤에만 밖으로 나간다. API 키·개인정보는 자동으로 가린다.
5. **해시 체인은 그대로.** PC와 서버 양쪽에서 만들고 대조한다(`core/chain.py`). 기록을 나중에 고치면 "조작됨"이 뜬다.
6. **"증명하는 것 / 증명하지 않는 것"을 나란히 쓴다.** "AI를 안 썼다"는 증명하지 않는다.

## 3. 모드 → 과제 유형

- `mode: learn | proof` 개념을 **없앤다.**
- 대신 **과제(Work)에 `ai_policy: "forbidden" | "allowed"`** 를 둔다. 과제 만들 때 고르고, 요약을 낼 때 바꿀 수 있다.
- **기록은 유형과 상관없이 똑같이 한다** (내용 포함, 아래 4절). 유형은 **출력(요약 1장)만** 바꾼다.
- 기존 수집기의 `if self.mode == "learn"` 분기(내용 수집 여부)는 **항상 수집**으로 바꾸되, 첫 실행 동의 화면의 **항목별 켜고 끄기**는 유지한다.

### 4-3. 새로 만든다 — 필수 기능 (제안서 3장, 13주까지)

**① 작성 과정 자동 기록**
- 완료 기준: 과제 시작 후 ChatGPT 답을 복사해 VS Code에 붙이면, 기록 화면에 **질문·답·붙인 위치가 한 줄로** 뜬다.
- 필요한 것: 확장이 AI 질문·답 원문을 기록(미실시 테스트, 10월 1주) + 붙여넣기 해시 매칭(완료).

**② 요약 1장 (두 종류)**
- 완료 기준: "과제 끝"을 누르면 1장 PDF가 나온다.
  - **AI 금지 과제:** AI 답 붙여넣기 건수, 작업 시간, 직접 입력 양
  - **AI 허용 과제:** 쓴 AI, 질문 수, 결과물에서 AI 답과 연결된 곳(그대로/고침), 출처 기록 없음 구간
- **요약은 규칙 기반이 기본** — 기록에서 센 숫자로 만든다(지어낼 수 없음, 외부 전송 없음, 비용 0). LLM 문장 요약은 **학생이 켤 때만** 쓰는 선택 기능이고, 결과는 학생이 확인·수정 후 제출한다.

**③ 의심받을 때 과정 공개**
- 완료 기준: 공유 링크를 열면 학생이 확인한 연결마다 **원래 AI 답과 고친 결과가 나란히** 뜨고(점수 없음), 기록을 고쳤으면 "조작됨"이 뜬다.
- 필요한 것:
  - 서버: 공유 링크 생성(토큰) · 읽기 전용 조회 · 체인 검증 결과 포함
  - 화면: 읽기 전용 공개 화면 (교수는 로그인 없이 링크로)
  - **가리기:** 학생이 제출 전 가린 부분은 "가림"으로 남는다(내용은 안 보이고, 체인 검증은 해시로 계속 됨)

**AI 답 연결 규칙 (②③ 공통)**
- 붙여넣기 해시가 AI 답과 같으면 → **사실이므로 자동 연결**.
- 해시는 다르지만 내용이 비슷하면(고쳐서 붙임, 보면서 다시 침, 두 답을 합침) → Trace가 **"이 문단이 3번 AI 답과 비슷해요, 연결할까요?"라고 제안**하고 학생이 맞다/아니다를 고른다.
- 학생이 "아니다"를 골라도 전체 기록에는 **"Trace가 연결을 제안했고 학생이 연결하지 않음"** 이 남는다(지울 수 없음, 체인에 포함).
- **퍼센트 유사도는 화면에 절대 내지 않는다.** 원문과 결과를 나란히만.
- 비교 단위: **문장**. 정확도가 부족하면 **문단** 단위로 축소한다.

### 4-4. 새로 만든다 — 확정 추가 과제 (이 대화에서 합의, 필수 기능 다음 순서)

| # | 과제 | 방법 | 완료 기준 |
|---|---|---|---|
| A | **VS Code 확장** | `onDidChangeTextDocument`로 변경을 실시간으로 받는다. 한두 글자씩 = 타이핑, 여러 줄 + 클립보드 일치 = 붙여넣기, 여러 줄 + 클립보드 무관 = "한 번에 들어온 코드(출처 기록 없음)", 에디터 밖에서 파일이 바뀜 = "외부 도구가 수정". **과제 폴더(작업 공간) 안, Trace 켠 동안만.** Cursor·Windsurf에서도 같은 확장이 돈다. 기존 저장 파일 diff는 다른 편집기용으로 유지 | 아래 5개 시나리오가 전부 맞게 표시됨 |
| B | **Claude Code 기록 읽기** | `~/.claude/projects/` 아래 세션 `.jsonl`을 읽어 지시문·수정 파일을 "외부 도구가 수정" 이벤트에 연결 | 터미널에서 Claude Code로 고친 파일에 지시문이 붙어 나옴 |
| C | **한글 hwpx 저장 비교** | hwpx는 zip 안의 XML → 파이썬으로 글자를 뽑아 저장 전후 비교 (docx와 같은 방식). 옛 .hwp·실시간(COM)은 제외. 테스트 파일은 한컴독스 무료판이나 학교 라이선스로 만듦 | hwpx 저장 시 "+n자/-m자, 붙여넣은 자리"가 남음 |
| D | **AI 대화 가져오기** | ChatGPT·Claude의 **전체 대화 내보내기 파일**을 한 번 올리면, Trace가 과제 기간의 대화만 추리고 결과물과 비슷한 대화를 연결 제안. 공유 링크 붙여넣기도 지원 | 내보내기 파일 1개로 데스크톱 앱에서 한 대화가 내역서에 연결됨 |
| E | **데스크톱 AI 앱 화면 읽기 (시험)** | Windows 접근성(UI Automation)으로 Claude 데스크톱 앱 창의 대화 텍스트를 읽는다. **AI 앱 창으로만 제한.** 화면 캡처·OCR·키보드 후킹은 하지 않는다 | 10월 기술 테스트에서 반나절 시험. 안 되면 D(가져오기)로 대체하고 향후 계획으로 |

**VS Code 확장 시험 시나리오 (A의 완료 기준)**
1. ChatGPT 코드 붙여넣기 → 해당 AI 답과 연결됨
2. 붙인 코드를 고침 → "고침"으로 원문과 나란히 보임
3. Copilot 자동완성 수락 → "한 번에 들어온 코드(출처 기록 없음)"
4. 터미널에서 Claude Code로 수정 → "외부 도구가 수정" (+ B가 되면 지시문)
5. 직접 타이핑 → 표시 없이 기록만

## 6. 구조 (제안서 4장 기준)

```
학생 PC
 ├─ 기록기 (Python) ── 창·입력 횟수·복사/붙여넣기·Word/PPT·hwpx·저장 diff·git
 ├─ 브라우저 확장 ──── AI 사이트 질문·답
 ├─ VS Code 확장 ──── 에디터 안 변경 (타이핑/붙여넣기/한 번에 들어옴/외부 수정)
 └─ Claude Code 기록 읽기
        │ 기록 전송 (체인 해시 포함)
        ▼
 Flask 서버 ── 출처 찾기(해시·유사도) · 체인 재계산·조작 검증 · 규칙 기반 요약 · 공유 링크
        │                                   └─ (선택) OpenAI·Qwen API: 요약 문장
        ▼
 SQLite ── 기록 · AI 대화 · 해시 · 연결(학생 확인 결과) · 가림 · 공유 토큰
        ▼
 React 화면 ── 학생: 요약·내역서·연결 확인·가리기·PDF / 교수: 공유 링크(읽기 전용)
```
