## 1. 한 줄로

**Trace = AI를 허용하고 대화 내역을 내라고 하는 학부 과제에서, 기록 → 출처 보기 → 제출 전 다듬기 → 공개를 자동으로 해 주는 도구.** 잡는 도구가 아니고, 표절률 · 확률 판정 없음.

## 2. 왜 바뀌었나 — 교수님 피드백 두 번 + 우리끼리 정리

1. **"사용자 · 써야 할 이유가 불명확하다"** → 사용자를 "지금 이미 대화 내역을 요구하는 교수"로 다시 정함 (v2.0)
   - 근거: 명지대 대화 로그 증빙서 필수 · 연세대 · 이화여대 명령어 제출 · 한양대 한 수업(GPT 질문 내역 전부 제출, 복붙 감점) · 대교협 가이드라인 있는 56곳 중 32곳이 AI 사용 공개 요구
   - "미래에 필요해질 것" 논리는 버림
2. **(10/28) "표절 기준을 적용해서 잡는 데서 끝내지 말고 학생이 고쳐 쓰게(revise) 해라. 카피킬러랑 합쳐라. B2B · B2C 둘 다 된다."**
   - 처음엔 표절 점검 엔진(지침 유형 · 6어절 · 바꿔 쓰기 유형 · 참고문헌)을 크게 잡았는데 (v2.1)
   - **(10/31) 다시 줄임 (v2.2):** 과제와 논문은 원하는 게 다르다. 과제 교수 규칙은 "대화 내역 내 · 복붙 감점"이지 표절률이 아님. 그리고 출처 보기가 이미 제출 전 점검 역할을 하고 있음 → **새 엔진 없이 출처 보기에 세 가지만 더함.** 논문용 엄격 점검은 다음 단계로.
3. 교수님 말 "AI 사용 내역은 원래 다 공개해야 하는데 귀찮아서 안 한다"는 **반은 맞고 반은 과장**이었어. 논문은 공개 규정이 있는데 46%가 다 안 밝힘(OUP). 과제는 의무가 아니고(56곳 중 32곳), 우리 설문에선 "아무 말도 못 들었다" 20명 · "가이드라인 처음 듣는다" 28명. → 발표에서 이 문장은 **교수님 말씀으로만** 인용.

## 3. 무엇이 바뀌었나

| | 전 | 지금 |
|---|---|---|
| 사용자 | 학생 · 교수 (막연) | **첫 고객 = AI 허용 + 대화 내역을 요구하는 교수** · 쓰는 사람 = 그 수업 학생 · 다음 단계 = 대학원생 (논문) |
| 초점 | 과제 · 논문 다 | **학부 과제** |
| 쓸 이유 | 앞으로 필요해짐 | 지금 교수는 손으로 대조, 학생은 캡처 정리 → 그걸 줄임 |
| 흐름 | 기록 → 내역서 | **기록 → 출처 보기 → 제출 전 다듬기 → 공개** |
| 학생 단계 수 | 4개 | **그대로 4개.** 다듬기는 출처 보기 화면 안에 |
| 원칙 1 | 판정하지 않는다 | 확률 · 퍼센트 · **표절률** 안 냄. 다듬기는 출처 잇기가 찾은 사실만 학생에게 |
| 숨기는 학생 | — | 못 막는다고 인정 + 드러냄: 쓴 과정 기록 없음 · 기록 밖 변경 · 작성 모양 · 물어볼 곳 |
| B2C | 안 함 | 다듬기가 생기면 학생이 혼자 쓸 이유도 생김 → 그다음 단계 |

## 4. 새 기능: 제출 전 다듬기 (출처 보기에 더함)

| 더할 것 | 내용 |
|---|---|
| ① 고치러 가는 버튼 | AI 답 그대로 → [직접 다듬기] · [그대로 둠] / 출처 없는 웹 글 → [인용 달기] · [직접 다듬기] |
| ② 웹 글 출처 표시 확인 | 복사한 웹 글 문장에 따옴표 · 각주 · 출처가 있나. 교육부 지침 표절 정의 = "출처 표시 없이 활용" |
| ③ "다듬음 N" | 처음 출처 보기 결과와 제출 때 결과를 비교해서 셈. 교수 한 줄에 이 칸 하나만 늘어남 |

- 비교 대상은 **이미 기록하는 것**(AI 답 · 복사한 글)뿐. 새 비교 엔진 없음.
- **"걸린 문장"이라고 안 함** → "다듬을 곳". 빨간색 · 점수 없음.
- **AI 답 문장에 인용을 강요하지 않음** (AI 허용 수업에선 표절이 아니라 공개 문제 → 내역서가 함).
- **다듬을 곳 목록은 교수에게 안 감.** 교수는 "다듬음 N"(좋은 쪽 숫자)만. 원래 보이던 그대로 · 고침은 그대로 보임.
- **AI가 대신 안 고침.** GPT에게 "수동태로 바꿔 줘" 시켜 붙이면 출처 잇기가 그 GPT 답에 다시 이어서 "아직 AI 답 문장이에요"로 보임 — 피동 분석 기능 없이도.
- 논문용 다음 단계(기획서 4.6): 지침 가~라목 · 6어절 · 바꿔 쓰기 유형 · 참고문헌 확인 · 연 웹 페이지 본문 비교. **이번 1달엔 안 함.**
