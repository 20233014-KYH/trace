## 1. 한 줄로

**Trace = AI를 허용하고 대화 내역을 내라고 하는 수업에서, 기록 → 점검 → 고쳐 쓰기 → 공개를 자동으로 해 주는 도구.** 잡는 도구가 아니고, 확률로 판정하지 않아.

## 2. 왜 바뀌었나 — 교수님 피드백 두 번

1. **"사용자 · 써야 할 이유가 불명확하다"** → 사용자를 "지금 이미 대화 내역을 요구하는 교수"로 다시 정함 (v2.0)
   - 근거: 명지대 대화 로그 증빙서 필수 · 연세대 · 이화여대 명령어 제출 · 한양대 한 수업(GPT 질문 내역 전부 제출, 복붙 감점) · 대교협 가이드라인 있는 56곳 중 32곳이 AI 사용 공개 요구
   - "미래에 필요해질 것" 논리는 버림
2. **(10/28) "표절 기준을 적용해서 잡는 데서 끝내지 말고 학생이 고쳐 쓰게(revise) 해라. 카피킬러랑 합쳐라. B2B · B2C 둘 다 된다."** + "AI 사용 내역은 원래 다 공개해야 하는데 귀찮아서 안 하고 안 보는 것" → 점검 · 고쳐 쓰기 추가 (v2.1)

## 3. 무엇이 바뀌었나

| | 전 | 지금 |
|---|---|---|
| 사용자 | 학생 · 교수 (막연) | **첫 고객 = AI 허용 + 대화 내역을 요구하는 교수** · 쓰는 사람 = 그 수업 학생 · 다음 단계 = 대학원생 (논문) |
| 쓸 이유 | 앞으로 필요해짐 | 지금 교수는 손으로 대조, 학생은 캡처 정리 → 그걸 줄임 |
| 흐름 | 기록 → 내역서 | **기록 → 점검 → 고쳐 쓰기 → 공개** |
| 학생 단계 | 기록 → 출처 보기 → 연결 확인 → 내역서 | 연결 확인 다음에 **점검 · 고쳐 쓰기** 하나 더 (5단계) |
| 원칙 1 | 판정하지 않는다 | **확률로** 판정하지 않는다. 공개된 기준으로 원문과 비교한 **사실**은 보여 주고, 쓴 기준을 같이 적는다 |
| 숨기는 학생 | — | 못 막는다고 인정 + 드러냄: 쓴 과정 기록 없음 · 기록 밖 변경 · 작성 모양 · 물어볼 곳 |
| B2C | 안 함 | 점검이 생기면 학생이 혼자 쓸 이유도 생김 → 그다음 단계 |

## 4. 새 기능: 점검 · 고쳐 쓰기

**무엇과 비교하나**
- ✅ 1단계: AI 답 · 복사해 붙인 글 (이미 원문이 PC에 있음)
- ✅ 2단계: 기록 중에 연 웹 페이지 본문 (확장이 읽어서 PC에만 · 메신저 · 메일 제외 · **동의 화면에서 따로 켬, 기본 끔**)
- △ 기록 중에 연 PDF
- ❌ 기록 밖 모든 웹 · 논문 → 카피킬러에 맡김 (큰 DB가 필요하고, 검색 API면 학생 글이 밖으로 나감)

**어떤 기준으로** — 교육부 「연구윤리 확보를 위한 지침」 표절 유형을 하나씩 코드로

| 지침 유형 | 재는 것 | 1달 안 |
|---|---|---|
| 가. 그대로 | 원문과 연속으로 같은 어절 수 | ✅ |
| 나. 단어 · 문장구조 변형 | 단어만 바꿈 · 붙이거나 뺌 · 어순 · 능동↔피동 (Barrón-Cedeño 외 2013) | ✅ / 능동↔피동 △ |
| 다. 생각 | 못 잼 | ❌ |
| 라. 번역 | 영어 AI 답을 옮겨 씀 | △ |
| 출처 표시 | 따옴표 · 각주가 있나 | ✅ |
| 참고문헌 | 실제로 있는 문헌인가 (Crossref) | ✅ |

- "6어절 = 표절"은 법 · 지침 기준이 **아님** (카피킬러 관행). 기준 이름과 출처를 같이 보여 주고 교수가 고름.
- **바깥 API:** PC 안 언어 모델(kiwi 등) ✅ · Crossref(참고문헌 목록만 나감) ✅ · 네이버 웹 검색 다음 단계 · 상용 표절 API ❌
- **고쳐 쓰기:** 걸린 문장마다 [인용 달기] / [내 말로 다시 쓰기]. **AI가 대신 고쳐 주지 않음.** 내역서에 "점검 후 고침 N곳".

## 5. 정한 것 — 바꾸려면 꼭 말해 줘 ⭐

| 정한 것 | 너한테 걸리는 곳 |
|---|---|
| **교수 계정 없음.** 모아 보기도 비밀 링크가 열쇠 (학생용 제출 링크 · 교수용 보기 링크) | — |
| 빈 문서로 시작 설정 없음 → 교수 공지 규칙으로 ("기록 전부터 있던 글 감점") | — |
| 교수 화면 정렬은 2개만: 그대로 쓴 곳 많은 순(기본) / 쓴 과정 기록 없음 많은 순. 점수 · 등급 없음 | — |
| **"쓴 과정 기록 없음"(`noproc`)과 "직접 타이핑 · 이어진 AI 없음"(`none`)은 반드시 다르게 보이게** | 출처 보기 화면 |
| **작성 모양: 키 간격(타이밍)은 기록하지 않고 횟수만.** "4분 동안 2초 넘게 멈춘 적 없음 · 고침 0회" 같은 사실 문장으로만 | **기록기** — 멈춤 · 고침을 횟수/구간으로 셀 방법 |
| **웹 페이지 본문 읽기는 기본 끔 · 동의 따로 · 메신저 · 메일 제외** | **확장** (`background.js` · `content.js`) |
| DB에 더할 것: `assignments`(새로) · `works.assignment_id` · `statements.retain_until` · `checks`(새로, 원문 없음) | 서버 |
| 화면 문구: **"96% 같음" → "한 단어 다름"** 같은 사실 문장 · **"직접 씀" → "직접 타이핑 (이어진 AI 없음)"** | 출처 보기 · 교수 링크 |
