# 알려진 한계 (2026-10-09 ~)

> 시험하면서 찾은 "아직 못 하는 것"을 한곳에 모은다. 발표·내역서에서 인정할 것과, 나중에 할 것을 나눈다.
> 새로 찾으면 맨 아래 표에 한 줄 더하고, 해결하면 ~~줄을 긋고~~ 날짜를 적는다.

## 1. 방법상 못 잡는 것 (발표에서 인정)

| 한계 | 왜 | 대신 |
|---|---|---|
| **말을 완전히 바꿔 쓴 문장** | 글자 비교라 AI 답과 겹치는 말이 거의 없으면 못 찾는다 (10/5 시험: 겹침 0.07~0.16, 직접 쓴 문장 최대 0.20) | "출처 기록 없음"으로 둔다 — 직접 썼다는 뜻이 아님 |
| **다른 기기(휴대폰 등)에서 본 AI 답** | 이 PC 만 기록한다 | 판정이 아니라 소명 자료라는 점을 분명히 |
| **서버 관리자가 기록을 통째로 새로 만드는 것** | 서버 대조는 학생 쪽 조작만 막는다 | 나중에 외부 시간 도장(OTS) |

## 2. 아직 안 만든 것 · 미룬 것

| 한계 | 지금 상태 | 언제 |
|---|---|---|
| **Codex 같은 코드 에이전트** (Codex · Cursor · Claude Code 등) | 기록 안 됨. 에이전트가 키 입력·붙여넣기 없이 코드 파일을 직접 고쳐서, 지금의 채팅 읽기로는 못 잡는다. 잡는 길: 파일 변화(file_watch · file_diff) + 그 시간 키 입력 없음 + 에이전트 프로세스가 돌던 중 → "AI 에이전트가 쓴 코드". Codex 는 구독이 없어 직접 시험 못 함 — 원리는 Claude Code 로 시험 가능, 프로세스 이름은 구독자 한 명이 확인 | **미룸 (10/9 결정).** 추가 과제 A(VS Code·코드 쪽) 때. 설문에 "코딩 과제에 AI 에이전트를 쓰나요?" 넣어 우선순위 확인 |
| **사진·그림 출처** | 못 잡음 (클립보드는 글자만 · Word 는 문단 글자만 봄) | 인터뷰 확인 후 결정 (10/8). 필요하면 AI 그림부터 |
| **AI 가 만든 Word 파일의 출처** | "쓴 과정 기록 없음"까지만 — 어디서 왔는지(다운로드)는 모름 | 사진 출처와 같이 |
| **맥에서 데스크톱 AI 앱 읽기** | 윈도우만 됨 (맥은 접근성 권한 필요) | 미정 |

## 3. 되긴 하지만 부족한 것

| 한계 | 내용 |
|---|---|
| **ChatGPT 앱의 모델 이름** | 앱 화면 어디에도 모델 이름이 글자로 없어서 "ChatGPT 앱"까지만 남는다 (웹은 모델 이름까지) — 10/9 |
| **ChatGPT 앱의 Codex(워크) 모드** | 구독이 없어 시험 못 함. 화면 읽기가 안 돼도 앱에서 **복사한 글은 남아서** 붙여넣기는 AI 답으로 이어진다. 질문·답 원문 전체와 "보고 옮겨 친 글"은 못 잡음 |
| **붙여넣은 뒤 고친 짧은 줄** | 8자 미만 짧은 줄을 고치면(예: "나이: 24세" → "나이: 25세") 이을 수 없어 "출처 기록 없음" |
| **숨은 탭의 답이 "이전 대화"로 잘못 표시** | 60초 규칙으로 막아 두었지만 원인은 확정 못 함 (확장 0.3.6 · dbg.offs 로 관찰 중) |
